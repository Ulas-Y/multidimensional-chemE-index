Overview

This mini-wiki documents the relativistic fluid solver implemented in numpy_fluid_core.py. The solver targets a compressible 3+1 ADM formulation of general relativistic hydrodynamics and is backend-agnostic through the xp abstraction.

Current Status

  • The main solver is in numpy_fluid_core.py.
  • xp selects PyTorch with CUDA when available, otherwise NumPy.
  • Compressible GR hydrodynamics is evolved with EOS closure, without active pressure projection in the evolution loop.
  • Metric effects are included through spatial metric contraction, affine connections, and curvature source terms.
  • Time integration supports both explicit Euler and RK4.

Usage

Typical initialization and evolution pattern:

from numpy_fluid_core import XPBackend, RelativisticFluidSimulation

xp = XPBackend.select()  # chooses PyTorch+CUDA if available, else NumPy

sim = RelativisticFluidSimulation(
    n_dim=3,
    lapse=alpha_field,
    shift=beta_field,
    spatial_metric=gamma_field,
    extrinsic_curv=K_field,
    mass=mass_field,
    velocity=velocity_field,
    pressure=pressure_field,
    rest_density=rho0_field,
    internal_energy=epsilon_field,
    integrator_type='rk4'
)

for step in range(num_steps):
    sim.step(dt)
    diagnostics = sim.check_constraints()

Key Concepts

  • Backend Abstraction: xp wraps array operations to run on NumPy or PyTorch transparently.
  • 3+1 ADM Formalism: The code evolves fluid primitives and geometric fields on a spatial slice with lapse, shift, and metric.
  • Compressible EOS: Pressure is updated from an ideal-gas equation of state before RHS evaluation.
  • No active velocity projection: Pressure projection is available as a utility but not applied in the main compressible evolution path.
  • Time integrators: Supports explicit Euler and RK4 with full primitive-state updates.
